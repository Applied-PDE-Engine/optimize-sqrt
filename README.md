# Optimize-Sqrt (`sqrt_game`)

A lightweight, header-only C++ implementation for approximating square roots using the **Binary Search (Bisection)** algorithm, developed under **Applied-PDE-Engine**.

## 🔭 Overview

`sqrt_game` provides a customizable approach to computing square roots without relying on external math libraries like `<cmath>`. By leveraging C++ templates, it allows developers to balance execution speed and numerical accuracy by controlling floating-point precision, iteration limits, and error tolerance—making it ideal for game engines, physics simulations, and embedded systems.

## 🚀 Installation & Usage

Since this is a **header-only** library, no compilation or CMake build step is required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Applied-PDE-Engine
   ```

2. **Include the header in your C++ project:**
   Copy `sqrt_function.h` into your project directory and include it:
   ```cpp
   #include "sqrt_function.h"
   ```
